# Библиотека

Библиотека университета работает с понедельника по пятницу с 08:00 до 22:00. В субботу и воскресенье библиотека открыта с 10:00 до 18:00.

Студенты могут брать обычные книги на 21 день. Срок возврата можно продлить два раза, если книгу не зарезервировал другой студент.

Ноутбуки выдаются только для использования внутри здания библиотеки. Групповые комнаты можно бронировать максимум на два часа подряд.
